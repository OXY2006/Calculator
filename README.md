# Calculator Web App
This is a simple and modern web-based calculator built using HTML, CSS, and JavaScript. It supports all basic arithmetic operations and features a user-friendly interface with a responsive design and custom background image.

## Features
1) Perform basic operations: Addition, Subtraction, Multiplication, and Division

2) Real-time display updates as you input values

3) Clear and equals buttons for better control

4) Responsive layout compatible with desktop and mobile

5) Custom UI with:

i) Stylish button design and layout

ii) Dark mode container with glowing border

iii) Mathematical background image

## Technologies Used
1) HTML5

2) CSS3

3) JavaScript (ES6)
